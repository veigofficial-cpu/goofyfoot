# 🎨 SVG 로고 및 캐릭터 교체 가이드 (SVG Replacement Guide)

이 폴더(`svg/`)에 직접 제작하신 SVG 그래픽 파일(.svg)을 **아래 파일명으로 넣어주시면** 웹사이트에 즉시 적용됩니다.

---

## 📁 파일명 및 용도 안내

| 파일명 | 웹사이트 위치 | 설명 |
|---|---|---|
| **`logo.svg`** | 첫 페이지 상단 로고 (Goofy Foot®) | 브랜드 로고 SVG 파일 |
| **`character.svg`** | 로고 바로 아래 엠블럼 아이콘 (벌레/매미 캐릭터) | 매미/곤충 캐릭터 SVG 파일 |

---

### 💡 교체 방법
1. Illustrator, Figma 등에서 디자인한 SVG 파일의 이름을 **`logo.svg`** 또는 **`character.svg`** 로 변경합니다.
2. 이 `svg/` 폴더에 덮어쓰기(복사)합니다.
3. 웹사이트(http://localhost:9000)를 새로고침(`Cmd + R`)하시면 교체된 SVG 그래픽이 바로 적용됩니다!
