# 🖼️ Goofy Foot 이미지 교체 가이드 (Image Replacement Guide)

이 폴더(`images/`)에 원하시는 이미지 파일(.png 또는 .jpg)을 **아래 파일명과 동일하게** 넣어주시면 웹사이트의 이미지가 즉시 변경됩니다.

---

## 📁 이미지 파일명 및 규격 안내

| 파일명 | 위치 / 용도 | 권장 비율 & 규격 |
|---|---|---|
| **`hero.png`** | 웹사이트 맨 위 메인 대문 이미지 (Hero Bottle) | 1:1 정방형 (예: 1000x1000px) |
| **`offbeat.png`** | 제품 01: `No. 01 OFF-BEAT` 룸 스프레이 카드 | 1:1 정방형 (예: 800x800px) |
| **`wavedrift.png`** | 제품 02: `No. 02 WAVE DRIFT` 룸 스프레이 카드 | 1:1 정방형 (예: 800x800px) |
| **`nocturne.png`** | 제품 03: `No. 03 NOCTURNE SPACE` 룸 스프레이 카드 | 1:1 정방형 (예: 800x800px) |
| **`gallery_01.png`** | 하단 공간 갤러리 1 (Study & Library Space) | 4:3 비율 (예: 1200x900px) |
| **`gallery_02.png`** | 하단 공간 갤러리 2 (Minimalist Bedroom) | 4:3 비율 (예: 1200x900px) |
| **`gallery_03.png`** | 하단 공간 갤러리 3 (Night Sanctuary) | 4:3 비율 (예: 1200x900px) |

---

### 💡 교체 방법
1. 교체하고 싶으신 이미지 파일명을 위 표의 파일명(예: `hero.png`, `offbeat.png` 등)으로 설정합니다.
2. 이 `images/` 폴더에 덮어쓰기(복사)합니다.
3. 브라우저(http://localhost:9000)를 새로고침(`Cmd + R`)하시면 교체된 이미지가 즉시 반영됩니다!
